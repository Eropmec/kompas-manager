# Менеджер проектов и библиотек для КОМПАС-3D

Программа для работы с проектами КОМПАС-3D v24: обозначения по схемам и переобозначение, библиотека типовых элементов, импорт таблиц из PDF.

Сейчас в репозитории **прототип** (папка `proto/`). Он проверяет, что Kompas API умеет всё, на чём держится переобозначение:

- записывать «Обозначение» и «Наименование» в модель;
- перепривязывать компонент сборки к переименованному файлу;
- перепривязывать ассоциативные виды чертежа и обновлять штамп;
- сохранять чертёж под новым именем;
- не оставлять битых ссылок.

## Где взять exe

Каждое изменение в ветке `main` собирается автоматически. Готовый `KompasProto.exe` лежит в [Releases → последняя сборка](../../releases/latest).

Python ставить не нужно, нужен установленный КОМПАС-3D v24. Exe не подписан, поэтому Windows при первом запуске может показать предупреждение SmartScreen: «Подробнее» → «Выполнить в любом случае».

## Тестовый проект

Сделай с нуля в отдельной папке:

- головную сборку, в ней подсборку;
- в подсборке две детали;
- ассоциативный чертёж одной из деталей;
- сборочный чертёж и спецификацию головной сборки (спецификация связана со сборкой).

Обозначения и наименования — любые эскизные. Перед запуском закрой файлы проекта в КОМПАСе.

## Порядок проверки

1. **Разведка.** Выбери папку проекта и нажми «Запустить разведку». Программа только читает файлы и показывает, что видит API. Отчёт — `probe_report.txt` в папке проекта. Если в отчёте есть ошибки, повтори с галочкой «Подробно».
2. **Тест переобозначения.** Выбери деталь, введи новое обозначение и наименование, нажми «Переобозначить на копии». Рядом с проектом появится копия `<проект>_proto_<дата_время>`, вся работа идёт в ней. Отчёт — `rename_report.txt` в копии.
3. **Ручная проверка в копии:**
   - головная сборка открывается без предупреждений о ненайденных файлах;
   - в чертеже детали виды построены, в штампе новые обозначение и наименование;
   - после синхронизации спецификации со сборкой строка детали получила новые обозначение и наименование.

По отчётам правится `proto/kompas.py`: все вызовы Kompas API собраны в нём.

## Запуск из исходников

```
pip install -r requirements.txt
python proto/app.py
```

Скрипты можно запускать и без окна: `python proto/probe.py <папка>` и `python proto/rename_test.py <папка> <деталь> <обозначение> <наименование>`.
